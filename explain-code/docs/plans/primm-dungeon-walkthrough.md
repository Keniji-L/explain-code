# Walkthrough: ผสาน PRIMM เข้ากับดันเจี้ยน 2D และเปลี่ยนการตอบผิดเป็นคำอธิบายแนวคิด

## สิ่งที่ได้ดำเนินการ

### 1. เหลือเฉพาะโหมดดันเจี้ยน 2D และผสานจุดเด่นจาก PRIMM ([TopicDungeonArena.tsx](file:///C:/Users/User/Documents/GitHub/explain-code/explain-code/app/components/dungeon/TopicDungeonArena.tsx))
- ลบปุ่มสลับโหมด `โหมด PRIMM คลาสสิก / โหมดดันเจี้ยน 2D` และ `<PracticeArena />` ออก ให้ผู้เล่นโฟกัสที่ดันเจี้ยน 2D เพียงโหมดเดียว
- **Interactive Line-by-Line Trace**: เพิ่มปุ่มสลับ `</> โค้ดเต็ม` กับ `👣 ไล่ทีละบรรทัด` ในแผง *"คัมภีร์โค้ดประจำด่าน"* เพื่อดูการทำงานทีละบรรทัดและค่าตัวแปรจาก `activeTopic.steps` ก่อนเดินไปปะทะมอนสเตอร์
- **ภารกิจโบนัสซ่อมโค้ด (Modify Bonus)**: เมื่อปราบมอนสเตอร์และประตูเปิดแล้ว จะแสดงการ์ดให้ผู้เล่นลองแก้โค้ดจริงและกด `รันทดสอบ` (`runCodeByLanguage`) เพื่อรับโบนัส `+25 XP`

### 2. เปลี่ยนจาก "เฉลย" เป็น "คำอธิบายแนวทางคิด" เมื่อตอบผิด ([BattleOverlay.tsx](file:///C:/Users/User/Documents/GitHub/explain-code/explain-code/app/components/dungeon/BattleOverlay.tsx))
- เมื่อตอบผิด: **ไม่ไฮไลต์ข้อถูกสีเขียว** (ไฮไลต์เฉพาะข้อที่เลือกผิดเป็นสีแดง) และแสดง **คำอธิบายแนวคิด (Concept Guidance)** แทนการเฉลยคำตอบตรงๆ
- เมื่อกด **ลองโจมตีเฟสนี้อีกครั้ง (Retry)**: ตัดข้อที่ตอบผิดออกให้อัตโนมัติเพื่อให้ผู้เล่นคิดวิเคราะห์จากตัวเลือกที่เหลือ
- เมื่อตอบถูก: ไฮไลต์ข้อถูกสีเขียว + แสดงคำอธิบายเต็ม + แสดง `+MP` ตรงตามค่าฟื้นมานาของตัวละครแต่ละคลาส
