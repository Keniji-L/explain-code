# CODE COOL — บันทึกส่วนที่ยังทำไม่เสร็จ / แผนพัฒนาต่อในอนาคต (WIP Roadmap)

## 1. ระบบของรางวัลระดับแรร์จากกล่องลับ Mimic (Implemented)
- **สถานะปัจจุบัน:**
  - ลดอัตราการเกิดหีบในห้องปกติเหลือ ~35% และเพิ่มโอกาสเจอกล่องลับ Mimic ~12% ของหีบที่เกิด (`app/lib/dungeon/mapgen.ts`)
  - กล่องลับ Mimic สุ่มโจทย์ระดับ `hard` (`getMimicChestQuestion` ใน `app/lib/dungeon/questions.ts`) ห้ามใช้สกิล/AI ช่วย
  - หากแพ้: เสีย 1 HP พร้อมแสดงคำอธิบายเฉลยแบบละเอียด (`app/components/dungeon/CodeChestModal.tsx`)
  - หากชนะ: ได้รับโบนัส +80 XP / +60 G พร้อมปลดล็อกบัฟ **Code Slayer Crown (`mimic_omni_relic`)**: ฟื้น +1 HP, โล่กันดาเมจ +1, เติม +2 MP และคูณ 2 รางวัลทั้งชั้นทันที

## 2. ระบบเศรษฐกิจและการใช้เงิน (Coins / Gold Economy)
- **สถานะปัจจุบัน:**
  - บันทึกและส่งต่อค่า MP (`focus`), Coins, XP และ Hearts ข้ามชั้นและข้ามบทเรียน
  - เพิ่ม **ร้านค้าระหว่างชั้น (`CoinShopModal`)** ใช้ Coins ซื้อยาฟื้น HP (+1 HP), น้ำยามานา (+2 MP), คัมภีร์โล่ (+1 Shield) และเครื่องรางคูณ 2 รางวัลระหว่างรัน
- **สิ่งที่พัฒนาต่อได้ในอนาคต:**
  - เก็บยอด `total_coins` และ `total_xp` สะสมถาวรลงฐานข้อมูล **Supabase** ระดับบัญชีผู้ใช้เพื่อซื้อสกิน/กรอบอวาตาร์ถาวร

## 3. การรองรับภาษาอังกฤษ (EN) ในโหมดรอง `/depths`
- **สถานะปัจจุบัน:**
  - หน้าหลัก, คอร์ส, บทเรียน, ดันเจี้ยนหลัก, หน้าอธิบายโค้ด, และหน้าครู รองรับ TH/EN ครบแล้ว
- **สิ่งที่ต้องพัฒนาต่อในอนาคต:**
  - เพิ่มคำแปลภาษาอังกฤษในไฟล์ข้อมูลโหมด `/depths` (`app/lib/dungeon/tacticalMonsters.ts`, `tacticalEngine.ts`, `dungeonPlanner.ts`)
