# CODE COOL — บันทึกส่วนที่ยังทำไม่เสร็จ / แผนพัฒนาต่อในอนาคต (WIP Roadmap)

## 1. ระบบของรางวัลระดับแรร์จากกล่องลับ Mimic (WIP)
- **สถานะปัจจุบัน (`2b0bb35`):**
  - ลดอัตราการเกิดหีบในห้องปกติเหลือ ~35% และเพิ่มโอกาสเจอกล่องลับ Mimic ~12% ของหีบที่เกิด (`app/lib/dungeon/mapgen.ts`)
  - กล่องลับ Mimic สุ่มโจทย์ระดับ `hard` (`getMimicChestQuestion` ใน `app/lib/dungeon/questions.ts`) ห้ามใช้สกิล/AI ช่วย
  - หากแพ้: เสีย 1 ❤️ พร้อมแสดงคำอธิบายเฉลยแบบละเอียด (`app/components/dungeon/CodeChestModal.tsx`)
  - หากชนะ: ได้รับโบนัส +80 XP / +60 G พร้อมป้ายแจ้งเตือน `🎁 ของรางวัลระดับแรร์จาก Mimic (ส่วนนี้ยังไม่เสร็จ / กำลังพัฒนา)`
- **สิ่งที่ต้องพัฒนาต่อในอนาคต:**
  - ออกแบบและเพิ่มตารางสุ่ม/เลือก **ไอเท็มระดับแรร์ (Rare Relics / Buffs)** จากการปราบ Mimic (เช่น โล่อมตะ 1 เทิร์น, ฟื้นฟู HP+MP เต็ม, ตัวคูณรางวัลทั้งดันเจี้ยน, หรือไอเท็มสะสม)

## 2. ระบบเศรษฐกิจและการใช้เงิน (Coins / Gold Economy)
- **สถานะปัจจุบัน (`c06bd3f`):**
  - บันทึกค่า MP (`focus`), Coins, XP และ Hearts ข้ามชั้นและข้ามบทเรียนลง `localStorage` พร้อมใช้ค่า MP จริงตามคลาสฮีโร่
- **สิ่งที่ต้องพัฒนาต่อในอนาคต:**
  - เก็บยอด `total_coins` และ `total_xp` สะสมถาวรลงฐานข้อมูล **Supabase** ระดับบัญชีผู้ใช้ (ใช้ข้ามเครื่องได้)
  - เพิ่ม **ร้านค้าระหว่างชั้น (Dungeon Shop / Campfire)** สำหรับใช้เหรียญในรอบนั้นซื้อ Potion (+1 HP), Mana Crystal (+2 MP), โล่ (+1 Shield) หรือแว่นตรวจจับ Mimic
  - เพิ่ม **Meta-Progression Shop** ใช้เหรียญสะสมปลดล็อกสกินฮีโร่, กรอบอวาตาร์, หรือโหมดท้าทายพิเศษ (Boss Rush)

## 3. การรองรับภาษาอังกฤษ (EN) ในโหมดรอง `/depths`
- **สถานะปัจจุบัน:**
  - หน้าหลัก, คอร์ส, บทเรียน, ดันเจี้ยนหลัก, หน้าอธิบายโค้ด, และหน้าครู รองรับ TH/EN ครบแล้ว
- **สิ่งที่ต้องพัฒนาต่อในอนาคต:**
  - เพิ่มคำแปลภาษาอังกฤษในไฟล์ข้อมูลโหมด `/depths` (`app/lib/dungeon/tacticalMonsters.ts`, `tacticalEngine.ts`, `dungeonPlanner.ts`)
